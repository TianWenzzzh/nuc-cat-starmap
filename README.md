# 中北大学—校园猫咪档案Skill

**中北喵星图 · NUC CAT GALAXY**

中北校园里到底有多少只猫？2026年8月，我们把校园翻了一遍——宿舍楼、教学楼、绿化带、食堂后门，见到就拍，一部分照片来自自己蹲点，一部分是学长学姐投喂的，前后攒了194张。回来逐张比对归并，确认在册76只。然后，把这76只猫做成了一片会转的星空。

九月开学，这76颗星正好等着一届新生来认领——带着寻猫海报把校园走一圈，猫找到了，路也就熟了。

不想下载的话，在线版点开就玩：https://gdfmdvcmsj.coze.site

## 适用人群与边界

先说清楚这份档案适合谁：刚到中北的新生（开学第一周，跟着猫把校园逛明白）、中北的师生（你专业楼旁边可能真守着一颗星）、来中北逛校园的访客、喜欢校园猫或喜欢翻数据可视化的人。

**边界一句话：档案数据只关于中北大学（2026年8月普查的76只），别校的猫查不到。** 星图、喵签、图鉴的玩法谁来都能玩；想给自己学校做一份，普查到建图的流程在SKILL.md第四节，方法论是通用的。

## skill 介绍

每个学校都有猫，但很少有人说得清：一共多少只？长什么样？住在哪？

我们的做法是先普查、后建档，再让档案变成能逛的星图：

- 每只猫是一颗星，毛色决定星色——橘猫是暖橘星，狸花是青灰星，三花自带渐变
- 星等看人气，被拍到的次数越多，星等越高，环绕的光点也越多
- 星位是真的，每颗星落在它真实出没的地方。你的专业楼旁边，可能就守着一颗星

中北是"人民兵工第一校"，猫学员自然也要列队报到：喵校长墩墩、橘少校、设备安全官玄铁（全黑，很难拍）……每只猫都有昵称、军衔和工位，点开星星就是档案卡，照片、辨认特征、50字小传都在里面。

数据这关我们卡得很严。194张照片逐张比对，疑似重复、身份存疑的一律不收录，宁可少一只，不放一只错的：071号因为夜拍画质不够直接弃用，编号空着；076和077同框判读矛盾，双双出局。每一条取舍都记在《归并决策摘要.md》里，欢迎抽查。

## skill 可以干什么

**看星**

- 入夜寻喵：开场2550颗粒子汇成标题，随后镜头从猫群深处拉出来，星星按远近依次点亮
- 首页有一道三色极光垂帘，粒子标题的配色和它呼应
- 拖拽、滚轮、双指都能漫游缩放；点开星星，档案卡带着照片缓动展开
- 搜索框支持按喵名、军衔、岗位、特征搜；毛色chips一键筛选橘系/狸花/三花/黑白
- 星图志：毛色分布、军衔构成、档案Top5的统计看板，可点击直达
- 星域网络：实证搭档猫之间有流动连线（摔跤×陪练是真的天天掐）

**玩起来**

- 喵星导览：一键开剧场，镜头自动飞过墩墩、玄铁、摔跤、陪练、初雪、独眼六位旗舰，字幕逐站讲解
- 今日喵签：每天抽一只猫加专属签文，同一天大家抽到的是同一只，看看今天哪只猫罩你；签文可以一键朗读
- 今日偶遇：随机翻一只可见星的牌子
- 喵图鉴：开过卡的猫可以打卡"我遇见过它"，收集10/30/50只放流星雨庆祝
- 星轨：长曝光模式，星系加速旋转拉出弧形光轨，校园地景退成鬼影底片
- 十二星宿：12大出没区升格为12座星座，金色星线连出守望者座、岁月座……点宿名听每座星官的故事
- 星尘变身：点开带照片的猫，星星先炸成一撮星尘，再缓缓聚合成它的照片
- 本命猫测试：5道题测出和你同频的那只猫，专属结果卡可以导出
- 猫星主题曲：每只猫的数据谱成一段专属旋律——毛色定调式、名字定动机，Web Audio实时合成

**带出门**

- 实地寻猫：12大出没区逐区列出常驻猫的识别特征，一键导出寻猫海报（竖版PNG）存进手机，真能带去校园里按图找猫——对新生这就是一张藏宝图：为了找墩墩你会走到宿舍楼玻璃门前，为了找玄铁你会认识设备区，一圈走下来，校园地形、楼群方位全摸熟了
- 喵星分享卡：一键导出720×1000星海报，直接发朋友圈
- 表情包工坊：档案卡里点"做成表情包"，猫照片变梗图，12句预设文案（"本喵今日不上班"）或自己写字幕，导出PNG发群里
- 喵星护照：记录你遇见的猫和点亮的星宿，按进度授称号，一键导出护照长图
- 喵星纪录片：导览时一键录屏成片，导出WebM直接发朋友圈

**彩蛋**

- 桌面端鼠标是一颗小彗星
- 访客彗星会周期性到访某只猫的星域，亮灯致意
- 天色按时辰渐变，猫聚簇的地方会漂起对应毛色的星云
- 星语音效：低频星海垫底加随机拨音，全部WebAudio代码合成，零音频文件（默认关闭）
- 秋季限定：9-10月开学季，星尘里会飘起金色落叶

## 常见问题

**我是新生，怎么用它最快融入校园？**
开学第一周导出一张寻猫海报存进手机，按12大出没区把校园走一圈：每亲眼见到一只就在图鉴里打卡，攒到第10只系统放一场流星雨。一圈下来你不仅认识了76位毛茸茸的学长，宿舍区、教学楼、食堂后门的地形也全摸清了——找猫是最低压力的逛校园方式，也是和同学最自然的破冰话题。

**打开黑屏，或"入夜寻喵"点了没反应？**
用 Chrome / Edge / Safari 16 及以上（IE 不行）；确认解压后整个文件夹在一起，没有单独把HTML拷出来。还不行就换个浏览器再开一次。

**照片显示不出来？**
照片加载失败会自动换成星夜占位图（一颗星星图案），不影响其他功能。整包重新解压一次通常就恢复了。

**搜索不到想找的猫？**
搜索认喵名、军衔、岗位和毛色特征，试试短词："橘"、"狸花"、"三花"、"校长"。还是搜不到的话，搜索框下面会给出几个可以直接点的建议名。

**图鉴收集的进度不见了？**
进度只存在当前浏览器的localStorage里：换浏览器、开无痕模式、清理浏览器数据都会清零；一直用同一个浏览器的话，不用登录也会自动累计。

**手机上有点卡？**
星空粒子效果比较重。关掉"星轨"模式、少开"星域网络"会流畅不少；体验最佳还是在电脑端。

**为什么只有76只？有的编号还空着？**
194张照片逐张归并的结果：疑似重复、画质不够的一律不收。071号因夜拍画质弃用、编号空着；076和077判读矛盾双双出局——每一条取舍都记在《归并决策摘要.md》里。

**数据过时了能自己加猫吗？**
能。在 `data/猫咪名册.csv` 补一行，再把HTML里的CATS数组同步补一只，完整流程见下方"数据与维护"。

**离线版和在线版有什么区别？**
功能完全一致，数据全部内嵌、不产生外部请求。在线版免下载点开就玩，离线版断网、机房照常跑。

**能用在自己学校吗？**
档案数据不能（那是中北的猫），方法论可以。SKILL.md 记录了普查、归并、建图到打包的完整流程，照着做就行。

## 数据与维护

- 数据源是 `data/猫咪名册.csv`，同时内嵌在HTML的CATS数组里，更新时两处保持一致
- 新增猫咪：CSV补一行记录，新星初次为种子随机落位，开校准模式拖到真实区域，导出JSON后把坐标写进HTML内CALIB表，固化后解压即用
- 落位约束：新星与既有星距离不小于0.05，同区域的猫相邻落位，避开山体、河流和图例区

## 隐私与合规

- 194张照片全部为校园实地拍摄，没有AI生成的猫像；逐张核验过，不含人脸
- 名册里的昵称、军衔、工位都是趣味设定，不涉及任何真实人物
- 纯前端单文件：零CDN、零外链、零上传；图鉴收集进度只存在浏览器localStorage，可随时清除

## 技术要点

- 单文件Canvas 2D，无外部依赖；发光用sprite缓存，dt步进兼容120Hz，DPR上限2
- 75张代表照与底图压至720px后以base64文本内嵌在 assets/photo-data-*.js，整包纯文本无二进制文件，兼容只收文本的平台；页面里PH()优先取内嵌数据
- 星轨长曝光：星系画在独立离屏层，轨迹缓冲只累积星系（lighter叠加加黑色透明衰减），不会把地图和UI糊成一片
- 星语音效：WebAudio振荡器、滤波、延迟全代码生成，遵守浏览器自动播放策略，默认关闭
- roundRect做了polyfill，兼容Safari 16以下；照片加载失败自动切换星夜占位图
