# 中北大学—校园猫咪档案Skill

> **中北喵星图 · NUC CAT GALAXY**
> 不是平面的卡片图鉴——是一张会转的**喵星图**。
> 这里的每颗星，是中北校园里的一只真猫。
> 76 只在编基米 ｜ 194 张学长学姐实拍 ｜ 2026-08 实地普查 ｜ 纯前端 · 完全离线可用

## skill 介绍

把校园流浪猫**实地普查数据**做成一片可以漫游的星空：每只猫是一颗星，**毛色决定星色**，收录照片数决定**星等**与环绕光点，**真实出没区域即它的星位**。

结合中北「人民兵工第一校」的基因，全体猫学员拥有自己的**军衔编制**——喵校长、橘少校、设备安全官玄铁（全黑），昵称、军衔、工位、50 字小传一应俱全。

数据全部来自 **2026-08 实地普查、194 张实拍照片逐一比对归并**：疑似重复个体、身份存疑候选一律弃用（编号跳号保留），宁缺毋滥——每颗星背后都有一条照片证据链。

## skill 如何使用

**方式一 · 直接打开（推荐）**：无需安装任何环境——

1. 解压本包；
2. 双击打开 `中北喵星图.html`（推荐 Chrome / Edge / Safari 最新版）；
3. 静待首页粒子汇聚成「中北喵星图」，点击 **入 夜 寻 喵**，坠入喵星系。

> 手机端同样可开：支持单指漫游、双指捏合缩放、点星开卡。

**方式二 · WorkBuddy 唤起**：在 WorkBuddy 对话框输入任一激活短语——

- 中北喵星图 ／ 打开喵星图 ／ 中北猫咪档案
- 看看中北的猫 ／ 校园猫档案 ／ 猫咪图鉴
- 抽个喵签 ／ 喵图鉴

## 数据与更新

- 数据源：`data/猫咪名册.csv`（同步内嵌于 HTML 的 `CATS` 数组，更新时两处一致）。
- 新增猫咪：在 CSV 与 `CATS` 中补记录 → 初次为种子随机落位 → 用校准模式拖到真实区域 →
  导出 JSON → 将坐标写入 HTML 内 `CALIB` 表（固化，解压即用）。
- 落位硬约束：全员限定校园核心建成区（归一化 x .33–.85 / y .16–.83）；与既有星距离 ≥ 0.05；同区域猫相邻聚簇；避开山体 / 河流 / 图例区。
- 低置信候选（疑似重复照 / 身份存疑）一律不收录，宁缺毋滥，决策留痕见 `归并决策摘要.md`。

## 隐私与数据合规

- **全实拍**：194 张照片均为校园实地拍摄，无任何 AI 生成猫像；AI 仅用于装饰物料（图标）。
- **无人脸**：普查照片逐张核验「人脸」列全部为「无」，不含可识别人脸。
- **无真实人名**：名册与页面仅含猫咪昵称/军衔/工位等虚构编制设定，不涉及任何真实个人隐私。
- **无外链**：纯前端单文件，零 CDN、零外部请求、零数据上传；所有计算与渲染均在本地完成。
- **数据治理**：低置信候选（疑似重复照/身份存疑个体）一律不收录，宁缺毋滥；归并决策全程留痕。

## 技术要点

- 单文件 Canvas 2D，无任何外部依赖，离线可运行；
- 三旋臂差速螺旋星系 + 预渲染星云 + 毛色聚簇星云 + 实况天色 + 双层视差星尘 + 流星雨（全程）；
- 星轨长曝光：星系绘制于独立离屏层，轨迹缓冲仅累积星系（`lighter` 叠加 + 黑色透明衰减），避免全帧糊化；
- 星语环境音：WebAudio 振荡器/滤波/延迟全生成，零音频文件，浏览器策略合规（默认关闭）；
- 发光 sprite 缓存替代逐帧渐变对象；`dt` 步进兼容 120Hz；DPR 上限 2；
- `roundRect` polyfill 兼容 Safari<16 / Chrome<99；照片加载失败自动切换星夜占位图；
- 纯本地运行，不上传任何数据；手动校准与喵图鉴收集进度仅存于浏览器 localStorage，可随时清除。
